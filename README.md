# 🚀 JavaScript Learning & Practice Journey

Welcome to my **JavaScript Learning & Practice Repository**! 🎯  
This repository serves as a personal notebook and documentation of my continuous journey in learning **JavaScript**. Here, I practice core concepts, write notes, solve problems, and structure my code to build a solid foundation in web development.

---

## 📌 Topics Covered & Practiced

Here is a summary of the concepts and topics I have practiced so far:

### 1. 🔤 Strings & String Methods
- **String Manipulations**: `toLowerCase()`, `toUpperCase()`, and `trim()` for handling user inputs.
- **String Operations**: `slice()`, `concat()`, `join()`, and searching with `includes()`.
- **String Reversal**: Reversing strings in 3 different ways (Built-in methods, `for...of` loop, and traditional `for` loop).

### 2. 📊 Arrays & Array Methods
- Fundamentals of Arrays and understanding **Zero-Based Indexing**.
- Updating and setting element values using index position.
- Adding and removing items using `push()`, `pop()`, `shift()`, and `unshift()`.
- Searching elements using `includes()` and finding positions with `indexOf()`.

### 3. ⚙️ Number Operations & Data Types
- String-to-Number Conversion using `parseInt()` and `parseFloat()`.
- Decimal Formatting using `.toFixed()`.

### 4. 🔀 Control Flow & Conditionals
- `if...else` conditional structures.
- Modern and concise conditional writing using the **Ternary Operator (`? :`)**.

### 5. 🔄 Loops & Iterations
- `for` loop, `while` loop, and `do...while` loop.
- Array & Object specific loops: `for...of` and `for...in`.

### 6. 📦 Objects in Depth
- Object literals, properties (keys), and values.
- Accessing & updating properties using **Dot Notation** and **Bracket Notation**.
- Working with **Nested Objects**.
- Object utility methods: `Object.keys()`, `Object.values()`, and deleting properties with `delete`.
- Looping through objects using `for...in`.
- Multiple ways of declaring objects in JavaScript.
